# text_as_data_winter2026
A course on computational text analysis

# Instructor: Segun Aroyehun

# Course description

A large and growing amount of human communication is available as digital text, offering a window into society, culture, and human behavior. This course provides an overview of issues in using text data for research. The content will cover features of text data, methods for measuring and validating constructs from text, and a range of research applications.

# Expectations

Participants are expected to actively engage with the course materials and contribute to discussions. Assessment will consist of three components:

1. Participation (20%): active engagement in class and with assigned readings.

2. Presentation (60%): preparation and presentation on a topic of interest, covering relevant data, methods, and findings.

3. Reflective summary (20%): a short written reflection (1 to 2 pages) on the chosen topic highlighting strengths and weaknesses. The summary should also outline a replication or reproduction scenario: if you had the opportunity to redo the selected study, what would you keep and what would you do differently?
